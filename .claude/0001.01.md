## O que foi entregue

**14 arquivos** organizados em dois grupos: o pacote `utils/smart_list` (reutilizável por qualquer módulo) e a integração com `books`.

### Pacote `utils/smart_list/` — motor reutilizável

| Arquivo | Responsabilidade |
|---|---|
| `config.py` | `SmartListConfig`, `ColumnDef`, `FilterDef` — declaração estática da lista |
| `renderer.py` | `SmartListRenderer.build_context()` — resolve estado atual (args, layout salvo, sort) e devolve `SmartListContext` pronto para o template |
| `export.py` | `export_csv`, `export_excel`, `export_pdf` — cada um retorna um `Response` Flask direto |
| `__init__.py` | exports públicos do pacote |

### Arquivos novos/alterados no projeto

| Arquivo | O que mudou |
|---|---|
| `model/user_layout_pref.py` | Novo model — persiste layout por usuário+lista |
| `api/routes/smart_list_routes.py` | `POST /api/layout/save`, `GET /api/layout/<id>`, `DELETE /api/layout/<id>/reset` |

### Como integrar em qualquer novo módulo

```python
# Em qualquer controller futuro
from utils.smart_list import SmartListConfig, ColumnDef, FilterDef, SmartListRenderer

MINHA_LISTA = SmartListConfig(
    list_id="usuarios",
    endpoint="users.list_users",
    columns=[ColumnDef("name", "Nome"), ...],
    filters=[FilterDef("search", "Buscar", type="text")],
    exportable=True,
    export_filename="usuarios",
)
```

O template é literalmente uma linha: `{{ smart_list(sl, row_actions=_row_actions) }}`.
